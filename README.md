# Мой проект это ТГ бот который будет давать советы как избежать потепление
## советы будут делится на 2 группы
### для маленьких детей - там будет объяснение что такое глобальное потепление, и что в нем плохого
### для подростков - там будут советы, и предложения что подростки смогут сделать
в самом боте будетут заранее заготовленые варианты того что бот может ответить и они будут рандомно выбиратся для нужной группы
